# E-Lite – E-Learning Platform

## Project Overview
E-Lite is a web-based e-learning platform developed as part of the Web Technologies Project at ESPRIT.

The platform allows:
- Course management
- Online quizzes and evaluations
- Virtual classes
- Forums and discussions
- User enrollment
- Anti-cheating system
- Google Sheets export
